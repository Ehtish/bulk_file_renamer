## Quick Recap

This project was built to practice basic Python file automation.

## Example

### Before

files_to_rename/
├── IMG_001.jpg
├── IMG_002.jpg
└── IMG_003.jpg

### After

files_to_rename/
├── image_001.jpg
├── image_002.jpg
└── image_003.jpg

Flow:

Files → Read → Rename → Next File

Main concepts:

- os
- File paths
- for loop
- Counter
- os.rename()
